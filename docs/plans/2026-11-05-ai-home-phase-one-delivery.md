# AI 小窝第一阶段完成计划

本计划以 [#155](https://github.com/wangyufengsky/qq-agents/pull/155) 两份 v0.4.2 设计为依据，对照已合并的 #156、#159、#160、#162、#163、#165 制定。跟踪议题为 [#166](https://github.com/wangyufengsky/qq-agents/issues/166)。维护者已授权分 PR 开发、验证、合并及现有部署交付；代码与隔离验收的证据见[一期验收说明](../AI-HOME-ACCEPTANCE.md)，实例部署和能力启用单独记录。

## 现有基础

纸页素材与统一布局、真实居民、三层导航和留言板、布局持久化、主体布置、原创介绍与三个文字作品槽位、撤回与管理隐藏、并发修订与幂等、身份代次及数据库备份已有实现。正式界面采用正视纸页与模块化家具，替代原讨论稿中尚未定稿的 2.5D 建议。

## 本期范围

- 页面只供实例管理员浏览；角色会话可读自己的房间和共享场景，不开放其他角色的房间正文或外部访客。
- 各角色 `@subject` 独占房间写入，公共客厅与走廊由管理员布置；管理员可隐藏内容，不能代写角色内容。
- 新意图、看图与项目快照能力独立默认关闭，旧实例和已启用基础小窝的角色不自动获得新能力；配置开关不代替权限、来源、模型能力和暂停校验。
- 作品快照限定为有可信来源证明的本人固定版本文字成果；不接任意文件、URL、聊天截图或完整私人项目目录。
- 意图提交只入队，在主体下次获准运行时提示数量，允许保持空白、拒绝或不处理。执行必须关联实际操作及回执，恢复不重复执行。
- 暂保留布局历史、身份代次、墓碑和必要拒重证据，不自动清理。正文按当前展示、撤回和队列状态的用途最小保存；保留内部元数据不等于继续公开正文。将来清理须另行证明旧请求无法重放。
- 新安装留言板显式开启；旧配置明确 true/false 保留，旧缺字段保持关闭。该规则不改变旧实例小窝受众、角色暂停和 QQ 发送权限。
- 二期串门与三期共同活动不属于本次完成范围。

## 交付验收

每个 PR 先运行相关定向测试，再完整运行 `npm run verify`；检查最新提交的 Windows 框架预检、三平台完整验证与 Docker 检查。界面及图片变更另做隔离浏览器验证。测试使用合成资料、假传输和独立临时数据，不向真实 QQ 发测试消息。

代码与隔离验收结果：

- [x] 意图提交、主体实际读取、接受/拒绝、原子执行、取消/过期、同请求重试与重启恢复。
- [x] 桌面和手机真实场景图片，权限及版本一致，无视觉时文字降级，撤回/隐藏/撤权及在途生成失效。
- [x] 门牌与固定成果的发布、版本、出处、并发、旧稿来源不足拒绝及撤回旧视图。
- [x] 空库与旧库重复打开、完整配置/数据库/资产备份恢复及旧版回滚演练。
- [x] 动态人数、键盘/焦点、窄屏、减少动态、配色可读性与资源/性能测量。
- [x] 两份原设计稿、当前指南、示例入口与配置说明对齐，保留真实未完成项。

实例交付在 [#166](https://github.com/wangyufengsky/qq-agents/issues/166) 与维护者交付记录中核对合并版本、本地同步、实际服务版本及角色连接、后端、暂停、会话和记忆元数据；上述代码验收勾选不代替部署证明。

代码完成、模拟验证、已部署、已启用和真实模型使用分别报告；不得由其中一项推定其余项成功。
