# 异地网页游戏接口设计 v0.4

状态：设计约定；仅 P0 验证程序随本次变更实现，P1–P4 尚未实现。本文将 v0.3 的游戏方向整理为可实施接口，并解决角色会话、断线、邀请凭据、后端对账与公网隔离的约定。不是上线或实测证明。

后续实现请从 [多游戏网页框架契约 v0.5](WEB-GAME-v0.5.md) 开始：五子棋是首个试点，通用内核与游戏模块分开。v0.5 明确替换本文的游戏专属结构、动作封装、AI 任务键及阶段安排；未替换的身份、邀请、安全、恢复和预算约束继续适用。本文保留为基线，不代表通用框架已经实现。

## 范围与阶段

核心体验：用户从 QQ 获取入口，在异地手机浏览器与同一个角色玩无禁手五子棋。15×15、黑先、连续五个或以上获胜、满盘无胜者和棋；首版一人一 AI，不做悔棋、换座或局中换规则。网页承载过程，QQ 只承载邀请、身份确认、必要异常和结束摘要。公网默认关闭。

| 阶段 | 交付                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------ |
| P0   | 独立测试服务、HTTPS 入口、显式加入、会话保持、测试落点、刷新和后台恢复；不接 QQ 或模型、不判胜负 |
| P1   | 权威规则、持久房间、完整身份/撤销/期限/幂等及故障恢复                                            |
| P2   | 先适配一个真实后端，可靠事件唤醒、租约、暂停、预算与结果对账                                     |
| P3   | 异地完成一局、认输、重入、断隧道与换域恢复                                                       |
| P4   | 只读棋盘观战、真实角色短评、进一步完善样式与部署向导                                             |

安全、身份、正确落子和恢复不推迟到 P4。P0 测试邀请只代表测试房间持有人，不代表 QQ 身份；P0 不可作为 P1 身份协议的生产替代。

## 角色、会话和运行门禁

- `agentId` 保持现有稳定身份；游戏不新建替身角色，也不改变 `connectionId`、`backendId`。
- 每个房间使用专属游戏上下文，概念键为 `game:<roomId>`，与原 QQ 聊天分开。只带角色公开资料、允许用于此房间的必要交接、当前裁剪棋局；不自动带入完整聊天、其他私聊或受保护工作。
- `originConversation` 由建房回合的已认证上下文派生，不接受网页指定。它用于授权、恢复邀请和结束摘要，并不等于游戏的模型会话键。
- 未来实现须给游戏范围显式增加调度与权限分支；不能把任意 `game:` 字符串塞进现有聊天唤醒接口。共享后端的并发能力不足时排队，不复用另一回合的可变上下文。
- 首版 QQ 断线时保留房间和网页会话，AI 任务显示 `blocked/QQ_NOT_CONNECTED`，停止新的模型执行与游戏写工具。恢复连接后重验版本、暂停和预算，登记原任务，不凭轮询重建任务。
- 全局/角色/来源会话暂停、静默、隔离模式、白名单、后端状态和预算优先。房间自身暂停是独立状态；解除房间暂停不解除管理员暂停。以后若支持 QQ 断线仍可玩，应作为独立策略变更。

## 身份、邀请与 HTTP

邀请分为公开入口与私密兑换凭据。公开入口只提供最小状态和加入申请；P4 前不提供旁观棋盘。`roomId` 不是授权凭据。

群内流程：网页发起加入申请 → 服务生成有期限的绑定挑战 → 用户在原 QQ 会话提交挑战 → 框架从真实消息发送者身份确认 → 浏览器取得该座位会话。挑战绑定房间、浏览器申请、预期参与人及期限；同一申请只能完成一次，不以昵称或浏览器提交的 QQ 号确权。

私聊定向邀请：框架在工具执行器内生成高熵令牌，经统一 QQ 发送器直接投递；模型只得到 `invitationId` 和投递状态，不得到私密 URL。发送账本为 `unknown` 时查询原回执，不重发新邀请。令牌只存摘要，访问日志、模型记录和公开群日志不保存原文。

首次 GET、QQ 链接预览、HEAD 和刷新均不兑换令牌。页面点击「确认加入」后才 POST；成功后 303 跳转至不带令牌的房间地址，使用 HttpOnly、Secure、SameSite Cookie。邀请寿命与会话寿命分开管理。写请求校验精确 Origin 与 CSRF 防护，跨源默认拒绝；不依赖 User-Agent 判定身份。

人类接口示意：

| 接口                               | 约定                                                                  |
| ---------------------------------- | --------------------------------------------------------------------- |
| `POST /rooms/:id/join`             | 显式兑换或完成已确认申请；拒绝过期、已兑换、撤销邀请                  |
| `GET /rooms/:id/view`              | 从 Cookie 推导座位，返回裁剪视图及 revision/eventSeq                  |
| `POST /rooms/:id/actions`          | `{actionId, expectedRevision, type, payload}`，身份不能放在正文中切换 |
| `GET /rooms/:id/actions/:actionId` | 仅当前主体有权查询其原回执                                            |
| `GET /rooms/:id/events?after=…`    | 有界增量；游标过旧时要求重取视图，不触发模型                          |

群内身份协议和私聊自动投递属于 P1/P2；P0 使用独立测试邀请。浏览器 Cookie 不跨域迁移；换域须回原 QQ 渠道重新确权、绑定原座位并撤销旧邀请。旧域已失效时不承诺能展示迁移页。

## 模型工具与不可变执行上下文

| 工具          | 参数与回执                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `game_create` | `(gameType, invitee, requestId)`；适配器派生来源身份、预算和短期请求票据。返回 roomId、入口状态、无凭据公开入口、邀请投递状态；不返回私密兑换 URL |
| `game_view`   | `(roomId)`；返回有权查看的棋局、轮次、合法动作、预算和阻断原因                                                                                    |
| `game_act`    | `(roomId, expectedRevision, actionId, move)`；适配器附加不可变 executionContext，模型不能填写                                                     |
| `game_close`  | `(roomId, requestId)`；按主体权限执行明确退出/结束语义，结束使未完成任务失效                                                                      |
| `game_say`    | P4：`(roomId, requestId, text)`；仅本人真实短评，独立限流，不影响落子                                                                             |

建房幂等键为 `(originConversation, actorId, requestId)`，保留建议 7 天；内部请求票据建议有效 10 分钟，适配层为同一调用保存票据，重试不能换新票据延长期限。入口未验证时可以保存待就绪创建操作，但不得返回可用邀请或重复建房。到期后的重试不隐式新建。

`executionContext={jobKey,runId,fencingToken}`，其中 `jobKey=(roomId,revision,agentId)`。由 worker 抢占任务时绑定到该次回合 ctx，经认证内部通道提交；旧调用不能查询最新 token 给自己升级。AI 写操作缺失上下文直接拒绝。人类操作只用浏览器认证，不允许请求字段选择主体类型。

## 权威状态、事务与事件

SQLite 可用于首版。房间状态为 waiting/active/paused/finished/expired，连接状态独立。开局、落子、认输、暂停、恢复、结束和过期递增 `revision`；短评、在线状态、探测和任务进度只增加 `eventSeq`。

动作唯一键 `(roomId,actorId,actionId)`；请求摘要覆盖类型、expectedRevision 和规范化参数。先认证与读取权限，再查旧回执；相同键同正文返回原回执，同键不同正文返回 `IDEMPOTENCY_CONFLICT`。新动作在同一事务内验证状态/权限/版本/规则/AI 租约，再写棋局、回执和 outbox。终局仍可查询旧成功回执；撤销后不能查询。动作记录与房间同时保留，删除后旧请求返回 `ROOM_UNAVAILABLE`，ID 不复用。

事件键 `(roomId,revision,agentId)`；outbox 与落子同事务，接收 inbox 持久去重，确认仅表示任务已登记。投递初次立即，随后 1/2/4/8/16 秒，±20% 抖动，每次超时建议 5 秒，总计最多 6 次；重启不重置次数。权限拒绝不重试，暂停进入 blocked。耗尽显示 delivery_failed，不判负；参与者重试在同一任务中互斥并检查预算。

## 租约、模型恢复与预算

内部 `claim(jobKey,workerId,claimRequestId)` 返回 runId、单调 fencingToken、leaseUntil；同一 claimRequestId 返回原结果。建议租约 60 秒、worker 每 15 秒续租；游戏服务不自行续租，使用自己的时钟与事务判断。过期心跳不能复活租约，版本推进/暂停/结束使旧任务失效。动作校验租约与写棋局必须处于同一事务。

续租失败且达到保守本地停止期限后，worker 停止新工具写入并尝试取消。远端调用是否已停止必须独立判断：持久记录 backendId、原生运行引用、runId、截止时间和已观察终态。只有后端证明旧调用终止才允许替代执行；缺乏查询能力或状态未知时设 outcome_unknown，不把本地超时、断线或进程恢复中的 interrupted 标记当作远端取消证明。

AI 状态：queued/running/blocked/delivery_failed/model_failed/outcome_unknown/completed。取得执行权才显示正在处理；120 秒仅提示等待，不判负。模型硬截止时间使用显式每局配置并受框架回合上限约束，不能靠续租无限延长。

每局必须设置有限的模型尝试数、总 token 上限或服务商可核算额度以及房间容量。调用前原子预留预算，后端自动恢复与最多一次非法动作修复都计入；预算不能只计算成功落子。用量未知时保留预留，不自动退款再试；无法提供硬 token 限制的后端不得声称费用可严格封顶。网页刷新、轮询和 P4 短评显示不触发模型。首个后端真实验收通过不代表其他后端通过。

## 期限、手机和公网入口

试用默认：空房 15 分钟；活动局 30 分钟无有效操作暂停；暂停 24 小时过期；终局保留 24 小时。轮询不续期，恢复要参与者确认且增加 revision；重开创建新 roomId。使用可控时钟验证边界。P0 为有固定截止时间的测试房间，不能冒充上述完整生命周期。

独立游戏进程只监听本机专用端口，只挂载游戏页面/API，不导入管理路由、真实配置、聊天数据库、文件库或通用代理。隧道只指向该端口；固定命令由部署者执行，模型工具没有终端权限。云端游戏服务是另一拓扑，需要框架出站事件通道。

入口状态 disabled/starting/ready/failed/degraded/stopped；分别记录 processHealthy、localHealthy、externalProbeStatus、checkedAt。只有独立外部请求拿到本次启动随机挑战才可记录外部验证成功；本机访问公网域名不能冒充独立网络探测。手机当次人工验证可作为明确记录的手工路径。未验证为 unverified，失败停止发新邀请，不清空棋局。P0 测试链接须显著标明未验证/临时性质。

手机先选点、查看坐标与局部放大，再点击独立确认，确认按钮至少 44×44 CSS 像素。保留缩放和坐标读屏标签。未知提交结果保留原 actionId，查询回执或重发原请求，不显示已成功。版本变化撤销旧预览。可见页短轮询 2–3 秒，后台暂停，失败退避并抖动，不重叠请求。SSR 输出有权看的快照，注明时间、非实时及刷新方式，无 JS 禁止写入。页面提供复制链接和 QQ 内置浏览器异常时换系统浏览器的提示。

## 必须验证的失败路径

- 并发重复提交、同编号不同正文、终局回执、撤销权限、删除后重试。
- 落子提交后投递前、接收后回执前崩溃；重启不丢事件或重置重试预算。
- 旧 runId/错误 agentId/缺上下文/伪造 token 拒绝；迟到工具不升级 token。
- 过期续租拒绝；暂停/结束竞争拒绝旧动作；模型状态未知不立即重启。
- 跨站写入、窃取 seatId、观战写入、恶意短评、公开路径访问管理台和日志泄密拒绝。
- 外部挑战失败不得 ready；换域重新确权；QQ 断线阻断 AI；每层重试计入预算。
- QQ 内置/系统浏览器各验证加入、落点、刷新、切后台、旋转与超时；无 JS 有快照。
