# 纠错、共同活动与框架自知

基线：PR #71 / 14d101d。三轮独立 PR，逐轮验证、合并，最后部署。

## 第一轮：纠错闭环

- 当事人或管理员的本轮完整可信来信可以纠正具体认识；记录旧判断、新解释、适用事件/时间与来源，不把转述当当事人授权。
- 原始聊天与日记历史不重写。直接目标附纠正，关联人物卡、相处记录、笔记、日记、意图沿证据进入持久检查清单；关联不表示整条内容错误。
- 搜索、原文读取、场景邻文、聊天回放、会话交接、人物卡、相处记录和空闲素材均携带后续解释。检查中断可继续；更新确认必须有实际记录变化，使用版本检查防覆盖。
- 保持角色隔离、受保护资料边界、原有 Self 回顾流程；导出恢复保留纠正；管理台可看纠正与待检查数量。
- 验收：解释未回复只是忙后，换会话、回查旧关键词和旧日记版本都能读到解释；旧感受和聊天保留。

## 第二轮：共同活动

扩展项目，保存参与者、活动场合、轮到谁、真实原稿、持续版本、进度与未决定选项。隔天继续可定位活动并读取当前原稿；不代替人作选择。活动历史不受个人项目最近30步裁剪。隔离场合与角色，支持导出恢复和管理台查看。

## 第三轮：框架自知

提供默认可用的本地框架说明、部署版本/后端/能力信息和本角色只读诊断。文档随代码版本，公开官方仓库可通过框架工具按本机提交或 main 读取固定目录文件，通用 GitHub 工具仍可扩展阅读。没有 GitHub 凭据或网络也能读本地说明；不暴露密钥、任意路径、其他角色资料；不授予写配置或执行命令权限。模型/桥接离线仍保留独立 doctor。
