# 意图取消与普通回复

只由主动意图唤醒的聊天回合，发送前需要选定意图。`intent_decide(cancel)` 或
`defer` 成功就已保存决定，但不会授权另发一条主动消息；没有新的人类输入时，
应结束本轮。`INTENT_DECISION_REQUIRED` 是发送前拦截，不表示取消失败，也不
表示 QQ 已收到消息。

人类可能在这类回合进行中发来新消息。模型通过 `conversation_read`、
`qq_wait_for_messages` 或完整的 `memory_read` 分页读到后，如果尚未选定发送
意图，回合可以继续普通回复。程序要求消息来自当前账号、当前聊天的可信真人，
序号晚于本次唤醒快照，正文完整可见且超过已消费的回复水位。到达但未读、旧消息、
截断摘要、其他聊天和机器人输入均不会解除限制。

切换只移除本轮“仅主动意图”限制，不修改意图的保存状态，也不清除私有仓库、
工作笔记或运维资料的保护标记。普通回复消耗普通回复预算，分钟/小时限速继续生效；
不消耗或清空主动联系次数。既有发送回执、未知投递和后端恢复防重发限制保持原样。

已经选定的意图继续绑定原发送检查及回执；新消息不能解除其过时检查。结束该回合后
由现有流程保存意图状态并处理下一次机会，不能把尚未处理的人类输入标为已处理。

单条工具错误与 `qq_send_burst` 的停止结果都会提供后续操作提示。模型应根据新消息
重新判断回复，不自动重放失败的连发；已经有回执的部分仍按原账本处理。

回归测试：`node --test test/intent-reply-recovery.test.mjs`。测试使用临时数据库、
真实桥接工具分发与模拟 QQ 网关，不发送真实 QQ 消息。
