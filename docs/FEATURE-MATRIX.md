语音和转发均通过共同 outbox、暂停、受限运维资料检查和发送限额；不能用其他发送工具绕开这些规则。自动任务的“已登记”“已运行”“模型完成但未发送”“已确认投递”“未知”有不同状态，不能互相替代。

[官方 NapCat API](https://napneko.github.io/onebot/api) 提供转发、语音及读取表情等接口；旧网关独有的扩展必须在目标版本核对。具体限制与操作方式见 [FEATURES.md](FEATURES.md)。真实后端矩阵输出在本机网关；另经明确授权，用独立手动进程通过 DSH/Codex QQ 连接只向用户本人私聊投递；DSH 三类、Codex 五类消息及一次拍一拍均由用户确认。两只原机器人继续暂停，没有生产切换。
