# 纸页小窝素材说明

本套素材按维护者提供的手绘立体书参考图委托 AI 生成：奶油纸纹、蜂蜜色木材、细棕色手绘线、米白裁切边与轻微纸层阴影。房间是一块不透明纸板，家具和装饰是独立透明纸片。所有姓名、状态和阅读内容由 HTML 呈现。

运行目录为 `public/home-preview/assets/`，共有 26 个 WebP 文件：

- 房间纸板 1 张。
- 房门、书桌、展示架、床、窗、窗帘、台灯、植物、地毯、挂画、介绍卡 11 张。
- 客厅沙发、茶几、留言板、小册、门牌 5 张。
- 简桌、宽展示架、落地灯、高植物、短窗帘 5 张。
- 浅蓝、豆沙床和地毯 4 张。

目录清单 `public/home-preview/catalog.mjs` 保存稳定 ID、`assetVersion`、原始尺寸与 alpha 显示边界、运行文件 SHA-256 和字节数，以及原始 PNG 的 `sourceSha256`、`sourceBytes`。运行文件总计 5,148,278 字节，原始 PNG 合计 52,836,414 字节。25 张纸片保留 alpha；纸板不透明。

## 来源与许可

生成工具为 OpenAI 内置 imagegen，制作提示词记录在 [generation-prompts.json](home-art/generation-prompts.json)。其中 `reference` 是制作时引用的参考稿标识，原始用户附件与制作参考稿不随运行资产发布。未下载第三方素材包。

这些生成素材作为本项目贡献，随仓库按根目录 [MIT 许可](../LICENSE) 提供，署名信息见 [NOTICE](../NOTICE.md)。来源说明不声称参考图的权利转移，也不声称 AI 输出具有独占权。后续替换素材必须保留准确来源、许可与版本记录，不能只替换图片而沿用旧哈希。

## WebP 转换

使用 `cwebp` 保持原尺寸，以质量 84 压缩颜色，alpha 质量 100；没有缩放、重新绘制或改变裁切边界。对每个原始 PNG 执行：

```sh
cwebp -q 84 -m 6 -alpha_q 100 input.png -o output.webp
```

原始 PNG 留在制作交付包中，不把约 53 MB 的制作源图重复放入运行仓库。复现转换需要匹配 `sourceSha256` 的 PNG，并核对本机编码器版本可能导致的字节差异；更换运行文件时重新计算哈希和体积。自动回归校验 WebP 标识、每个文件哈希与大小、显示边界及整套资源体积。

纸片按目录 `bounds` 显示：容器按可见边界计算长宽比，内部图片按原图比例偏移。这样素材外部透明留白不会影响模板锚点。资源加载失败显示占位，功能入口保持为 HTML 按钮。
