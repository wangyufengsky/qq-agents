# 纸页小窝素材说明

本套素材按维护者提供的手绘立体书参考图委托 AI 生成：奶油纸纹、蜂蜜色木材、细棕色手绘线、米白裁切边与轻微纸层阴影。房间是一块不透明纸板，家具和装饰是独立透明纸片。所有姓名、状态和阅读内容由 HTML 呈现。

运行目录为 `public/home-preview/assets/`，共有 27 个 WebP 文件：

- 房间纸板 1 张。
- 房门、书桌、展示架、床、窗、窗帘、台灯、植物、地毯、挂画、介绍卡 11 张。
- 客厅沙发、茶几、留言板、小册、门牌 5 张。
- 简桌、宽展示架、落地灯、高植物、短窗帘 5 张。
- 浅蓝、豆沙床和地毯 4 张。
- 墙上信封 1 张，采用奶油纸、麻绳挂环和陶红封蜡；信件标题与内容由 HTML 呈现。

目录清单 `public/home-preview/catalog.mjs` 保存稳定 ID、`assetVersion`、原始尺寸与 alpha 显示边界、运行文件 SHA-256 和字节数，以及原始 PNG 的 `sourceSha256`、`sourceBytes`。运行文件总计 5,277,540 字节，原始 PNG 合计 54,929,577 字节。26 张纸片保留 alpha；纸板不透明。

## 来源与许可

生成工具为 OpenAI 内置 imagegen，制作提示词记录在 [generation-prompts.json](home-art/generation-prompts.json)。其中 `reference` 是制作时引用的参考稿标识，原始用户附件与制作参考稿不随运行资产发布。未下载第三方素材包。

这些生成素材作为本项目贡献，随仓库按根目录 [MIT 许可](../LICENSE) 提供，署名信息见 [NOTICE](../NOTICE.md)。来源说明不声称参考图的权利转移，也不声称 AI 输出具有独占权。后续替换素材必须保留准确来源、许可与版本记录，不能只替换图片而沿用旧哈希。

## WebP 转换

使用 `cwebp` 保持原尺寸，以质量 84 压缩颜色，alpha 质量 100；没有缩放、重新绘制或改变裁切边界。对每个原始 PNG 执行：

```sh
cwebp -q 84 -m 6 -alpha_q 100 input.png -o output.webp
```

原始 PNG 留在制作交付包中，不把约 55 MB 的制作源图重复放入运行仓库。复现转换需要匹配 `sourceSha256` 的 PNG，并核对本机编码器版本可能导致的字节差异；更换运行文件时重新计算哈希和体积。自动回归校验 WebP 标识、每个文件哈希与大小、显示边界及整套资源体积。

纸片按目录 `bounds` 显示：容器按可见边界计算长宽比，内部图片按原图比例偏移。这样素材外部透明留白不会影响模板锚点。资源加载失败显示占位，功能入口保持为 HTML 按钮。

## 桌宠动作素材

站姿、跨步、收步各三张，发布在桌面小窝客户端的 `art/actions` 目录，按角色文件名前缀 `fish`、`dragon`、`cat` 和动作后缀 `stand`、`stride`、`step` 加载。9 张 WebP 合计 223,278 字节。

用同目录的三张 `*-idle.webp` 作参考，通过 OpenAI 内置 imagegen 生成三分之四侧面朝右的站姿和跨步画面，再以同一生成稿为参考补一张前脚着地、后脚屈起的收步画面。按 PNG 的 alpha 轮廓裁切、清理低透明度噪点，以 Lanczos 缩放到 300 像素高（收步 297 像素），底部对齐到 320×320 的透明画布后用 Pillow 转换为 WebP（质量 85，method 6）。坐姿继续使用原待机图。朝左由渲染器镜像，起停、转身、坐起和张望由 CSS 变换呈现。

动作帧随桌面小窝代码按根目录 [MIT 许可](../LICENSE) 提供。原始 PNG 是制作中间稿。现有纸片角色的创作参考和署名见 [NOTICE](../NOTICE.md#纸页小窝与桌面小窝生成素材)。
