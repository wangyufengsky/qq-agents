# GitHub 只读访问

每个角色可在「配置角色 → 联网与 GitHub」中开启 GitHub，只提供 `github_capabilities`、`github_search` 和 `github_read`。启用自主联网后，角色可以根据聊天需要或兴趣使用这些工具，无需 `/search` 指令。主体也可以读取。

公开搜索支持仓库、代码和 Issue/PR；文件和目录通过 GitHub Contents API 读取，长文件分页，不执行仓库里的命令。GitHub 的代码搜索需要登录，搜索索引覆盖和限流由 GitHub 决定，空结果不证明代码不存在。

## 登录与私有仓库

推荐新建 fine-grained personal access token，只选择需要的仓库，授予 Metadata、Contents、Issues、Pull requests 的只读权限，设置有效期，不授予写、管理或工作流权限。使用者自行确认对该仓库的数据共享权限。

在角色编辑器的专用密码框保存令牌，桥接会写入数据目录下的 `secrets.json`（仅当前用户可读写），并加载到进程环境变量，例如 `QQ_GITHUB_READ_TOKEN`。密码框留空保留原值，管理 API 不回显令牌。角色配置只记录变量名，不包含令牌正文。也可由启动环境直接提供变量。令牌不会返回给模型，也不放进 URL。另一种方式是显式选择本机 `gh` 登录：桥接只调用固定的 `gh auth token --hostname github.com`，不会让模型运行 CLI；但已有 CLI 令牌本身可能拥有写权限，风险大于专用只读令牌。认证失败不会降级为另一账号或凭据。

私有仓库必须逐一登记 `owner/repo`，不接受通配符，角色之间各自配置。私有读取只在管理台创建的独立受保护任务中允许，任务还需明确选择已登记仓库。普通私聊（含管理员）、群聊和空闲主体只能读公开内容。私有结果会送入该角色所选模型，并保留在本机受保护的工作记录中。

私有来源标记跟随工作记录与历史证据；不能通过再次检索旧记录绕过。工作上下文不具备 QQ、公开搜索、共享 Self 或意图写入工具，只能读取本任务声明的仓库。管理员在管理台审阅精确版本后，可将那段结果解除工作保护并交回普通记忆；原始资料继续隔离。详见 [独立受保护工作](PROTECTED-WORK.md)。这些限制覆盖桥接提供的工具；不能替代模型服务商的数据处理政策，也不控制桥接之外单独授权的本机工具。仅回到同一已授权私有仓库的读取可继续，不把「自主联网」当作私有代码披露授权。

## 网络与预算

请求固定发送到 `https://api.github.com`，仅 GET，不跟随重定向。公开搜索、仓库元数据检查和文件/目录读取均使用角色配置的 Token 或 `gh` 凭据，计入 GitHub 的认证额度；同一账号的凭据可能共享上游额度，仍可能遇到 GitHub 限流。认证失败不会降级成匿名请求。工具不提供提交、评论、Star、Fork、工作流触发或权限修改。

带认证不等于允许读取私有仓库。每次获取新内容前核对仓库名称与可见性；公开文件/目录获取后、返回模型和保存记录前，再检查仓库身份与公开状态，期间转私有或检查失败就拒绝返回。指定仓库的公开搜索也在收到结果后复核，未指定仓库的搜索按仓库去重复核并过滤私有结果。私有仓库仍须同时满足角色白名单与独立受保护任务声明，来源保护和外发限制保持不变。

同一回合内，相同仓库、路径与 ref 的读取共享已经校验通过的完整快照，包括并发请求、文件续页和目录续页；缓存命中不发 HTTP 请求，也不占 HTTP 请求预算。首次公开读取通常需要 3 次请求（仓库检查、内容、返回前复核），随后同文件分页不再重复下载。快照不跨角色或回合共享，凭据或 GitHub 策略变化后不复用，失败结果不缓存。续页读取的是该回合首次取得的快照，新回合重新获取；暂停、撤权和受保护任务范围仍逐次检查。不会把缓存的“公开”状态当作十几分钟内读取新内容的通行证。

每角色默认每回合 15 次、每天 150 次 HTTP 请求，仓库元数据核对也计数。网络请求在发出前计费到本地计数器，失败不自动重试；每日计数按 UTC 日期持久化。单次响应最多 2 MiB，文本文件最多 512 KiB；目录最多 50 项一页，文本最多 16000 字符一页。二进制、子模块及外链不作为文件正文读取。

配置示例：

```json
{
  "github": {
    "enabled": true,
    "auth": "token",
    "tokenEnv": "QQ_GITHUB_READ_TOKEN",
    "privateRepositories": ["example-owner/example-repo"],
    "maxRequestsPerTurn": 15,
    "maxRequestsPerDay": 150
  }
}
```

角色工具白名单也需包含上述三个工具。不能仅凭开关或凭据存在声称 GitHub 已连通；需要一次实际只读请求验证。
