# 纸页小窝场景预览

从纸页小窝页尾点击「查看示例与本机布置预览」，或打开同一管理台地址下的 `/home-preview/`。这是第一份家园实现：手绘纸板、可配置纸片，以及客厅、走廊和个人房间的响应式呈现。

页面上的住户、在线状态、留言、介绍和作品全部是明确标注的示例。页面不读取角色、聊天、记忆或管理凭据，不调用模型，不发送 QQ 消息；也没有真实房间保存接口。它与管理台共用回环 Host、Origin 和跨站检查，仅静态示例资源无需登录。没有开放公网入口。

## 试用

1. 在客厅点击留言板、小册或房门；走廊每页最多三间房。
2. 展开「布置这页纸」，选择纸片款式、偏移、缩放、层级、隐藏或镜像。桌上的卡片和灯跟随桌子，门牌跟随门，窗帘跟随窗户。
3. 切换三种配色。床和地毯使用对应织物素材，墙面使用轻微色层；文字不烘焙进图片。
4. 调整示例居民数，检查 0、1、2、3、4、7 人布局。手机上走廊逐门呈现，房间的休息角放到下方纸板，使用同一份配置。
5. 隐藏可点击家具后，仍可使用场景下方文字入口。图片加载失败显示占位；阅读面板支持 Esc、关闭按钮和焦点恢复。

预览布置仅保存在当前浏览器的 `qq-agents-home-preview-v1` 存储项。可以恢复默认、撤销本次页面会话中的最近 20 次操作，或导出 JSON；导出目前没有导入或真实房间发布入口。不同浏览器不会同步。浏览器拒绝本地存储时仍可预览和导出。

「页面状态」模拟空内容、加载、无权限、请求失败与素材缺失，用于检查呈现效果，不是实际服务状态。普通访问者能操作此预览，不代表获得真实角色的房间写权限。

## 代码与配置边界

| 文件                                | 职责                                                         |
| ----------------------------------- | ------------------------------------------------------------ |
| `public/home-preview/catalog.mjs`   | 26 项素材 ID、版本、尺寸、透明边界、压缩前后哈希、许可与来源 |
| `public/home-preview/templates.mjs` | 三种纸板模板、稳定锚点、桌面/手机映射、父子关系及语义入口    |
| `public/home-preview/scene.mjs`     | 可复用纯函数：创建配置、校验、解析纸片位置和继承关系         |
| `public/home-preview/app.mjs`       | DOM 渲染、导航、示例阅读面板与本机预览设置                   |
| `src/home/static.mjs`               | 固定文件白名单、MIME 和 CSP；只接受 GET/HEAD                 |

场景导出具有 `schemaVersion: 1`、`kind: scene-preview-only`、`sceneId`、`templateId`、`assetCatalogVersion: paperbook-v1`、`palette` 和 `objects`。`objects` 以实例 ID 为键，仅保存相对模板的覆盖值：

```json
{
  "desk": {
    "asset": "desk-simple",
    "assetVersion": 1,
    "dx": 4,
    "scale": 1.1
  }
}
```

此片段是 `objects` 字段，不是完整场景。覆盖值只允许目录中该实例的款式；偏移为横向 ±6、纵向 ±5，缩放 0.8—1.15，层级为 1—8 的整数，隐藏与镜像为布尔值。父级镜像同时改变子纸片横向落点与朝向，文字保持正向。子纸片至少高于父级一层，因此最终渲染层级可以超过覆盖值上限。

模板内的 `base`/`phone` 是锚点显示映射，坐标使用纸板百分比（x 为中心，y 为底边），不进入导出配置。手机 `zone` 只改变呈现分区。父子关系和入口动作由受控模板决定，配置不能注入脚本、URL、任意素材或入口。版本、字段或数值不合法的本机配置回退到默认场景。

这套范围检查不等于正式布局的占位、遮挡或写入权限校验。[真实小窝](AI-HOME.md) 已接入居民、服务端版本与公共布局保存/撤销及现有留言板；AI 主人格工具、公开内容、来源与权限、意图、受控看图另行实现。预览数据不自动迁移为角色房间，当前交付不代表第一阶段 A/B 验收完成。

## 验证

```sh
node --test --test-timeout=120000 test/home-scene.test.mjs
npm run verify
```

浏览器验收使用已安装的 Chromium/Chrome（不自动下载），临时数据库和假传输，不读取生产配置。指定浏览器绝对路径后运行：

```sh
CHROME_PATH="<浏览器可执行文件绝对路径>" node test/home-preview.browser.mjs
```

可用 `HOME_PREVIEW_OUTPUT` 指定截图和 JSON 报告输出目录，否则使用系统临时目录。检查桌面、375px 和 390px 手机布局、父子跟随、刷新保存、款式和配色、隐藏/缺图后的文字入口、阅读与返回焦点、坏配置恢复。浏览器模拟不等于手机 QQ 内置浏览器或真实 AI 发布验收。

素材制作与压缩见 [素材说明](AI-HOME-ASSETS.md)，完整设计方向见 [第一阶段讨论稿](plans/2026-11-04-ai-home-phase-one.md)。
