## 剩余事项

1. **真实接入验收尚未覆盖的部分**：Codex 机器人独立 QQ 连接的出站；图片、引用、@、拍一拍和官方表情扩展写入；跨群汇总的真实场景；黑话外部检索、平台登录及外部 MCP。相关主线代码已实现，不能把替身测试当作这些真实场景已通过。
2. **语音理解和生成能力仍需接入与验证**：目前能处理、播放和转发音频，但没有经过验证的语音识别/转录链路；当前 Codex 动态工具没有原生音频输入。外部语音/图像生成需要明确的服务与配置，再验证内容和投递。
3. **原生 NapCat 资源直读缺陷仍在**：本机 4.18.38 的协议后备路径没有初始化 PacketApi。统一桥接已可利用成功回执和已观察来源完整回读自己的发送，结果标明来源及网关警告；没有这些来源记录的第三方 JSON 转发卡片仍依赖原生网关修复。此次未修改生产网关。
4. **实际运维与生命周期验收**：真实但独立的工作区命令、平台会话、QQ/容器启停还需受控演练。现有本地权限测试不能替代部署环境验收。
5. **按要求暂缓的生产工作**：生产数据迁移/回退演练、双机器人联调和生产切换。现有两只机器人保持暂停，未经后续安排不进入这些步骤。

本轮全部在本机执行，GitHub 只用于代码与 PR 管理，没有 GitHub Actions。完整证据与限制见 [验收记录](ACCEPTANCE.md)，具体操作见 [功能说明](FEATURES.md)。
