# 已完成功能与剩余事项 · 0.4.0 · 2026-10-25

本版补齐外部 MCP 的真实发现与 HTTP 接入、本机可选 TTS、跨时间记忆关系和中文长词索引。现有两只生产机器人继续暂停，没有部署、迁移、自动重连或新增 AI 后端。本轮只有隔离网关投递；此前真实 QQ 客户端验收记录仍保留在 ACCEPTANCE.md。

合并前修复六项审查问题，组合版本 198 项本地测试及语法、格式、隐私检查通过；详见 [PR 审查与复测](PR-REVIEW-0.4.md)。生产保持暂停，本轮不部署或迁移。
