## 剩余事项

场景检索目前是有界的时间邻域与明确引用，不是群内多话题的语义分段。未知名称、历史缺失时间、未归档引用不会补猜。来源标签也不能保证模型的每次自然语言推断正确；实际测试曾观察到 DSH 对日记添加无证据后续经历，已强化提示，但长时间、并行话题和复杂关系的模型质量还需持续评估。

1. **真实接入验收剩余项**：群聊 @、官方表情扩展写入、跨群汇总；黑话外部检索、平台登录及外部 MCP。不能把本地替身测试当作这些真实场景已通过。
2. **语音理解和生成能力仍需接入与验证**：目前能处理、播放和转发音频，但没有经过验证的语音识别/转录链路；当前 Codex 动态工具没有原生音频输入。外部语音/图像生成需要明确的服务与配置，再验证内容和投递。
3. **当前网关的 PacketBackend 配置限制**：本机 Codex 网关原配置为 `packetBackend: disable`，导致拍一拍与部分原生转发资源读取失败。临时改为 `auto` 后，两项真实 API 均成功；测试后恢复原配置及在线状态。旧文档称“原生直读缺陷”的归因已修正。统一桥接的已确认发送来源回读不依赖该开关；缺少自己发送回执的第三方卡片仍依赖网关能力。后续正式启用 PacketBackend 属于部署配置步骤。
4. **实际运维与生命周期验收**：专用工作区命令、平台会话、新项目自己的 QQ/容器生命周期管理还需受控演练。本次使用原入口临时重启 Codex 网关，不代表新项目生命周期工具已通过实机验收。
5. **按要求暂缓的生产工作**：生产数据迁移/回退演练、双机器人联调和生产切换。现有两只机器人保持暂停，未经后续安排不进入这些步骤。

本轮全部在本机执行，GitHub 只用于代码与 PR 管理，没有 GitHub Actions。完整证据与限制见 [验收记录](ACCEPTANCE.md)，具体操作见 [功能说明](FEATURES.md)。
