## 运行和资源边界

正式浏览器每页最多三间房。基础角色读写、文字展示、意图、场景看图和项目快照分别受配置控制，新增能力默认关闭。每次布局批次最多 24 项；发布/布置每日额度可配置，默认 20 次。意图默认有效期 7 天、最多 20 条待处理、每日最多 20 次提交，均有配置范围；终态清除提议正文，必要元数据和幂等回执暂不自动清理。

场景看图采用固定桌面/手机视口、最多两路并发、每角色 5 秒间隔、20 秒生成预算和 4 MiB 图片上限。生成结束后，浏览器关闭等待最多 500 毫秒，进程树退出确认窗口为 POSIX 一秒、Windows 三秒；无法确认进程退出时不释放渲染名额。临时目录遇到系统文件锁最多重试三次，总退避 600 毫秒；永久失败仍返回错误，已确认进程退出的名额不会被目录删除失败占住。各步骤分别计时。固定限制不能由模型参数扩大。取消和失败关闭本次隔离渲染资源；不复用管理员浏览器或个人 profile。缺少浏览器、缺少视觉能力或生成失败时返回明确文字降级，不能声称已看见图像。冷启动超过同一预算时也明确降级，不自动重试；超时降级与真实 PNG 成功分别验收。

页面只加载当前场景使用的家具；同页和重复导航复用已加载图片/字体。首次字体仍为完整中文字库（8,098,988 字节），不是小字体包。字体采用 swap，本地字体可在下载前或失败时继续显示文字；家具失败显示缺失提示，文字入口继续可用。减少动态偏好关闭翻页动画，不改变布局或权限。

## 可重复验证

在已安装依赖的独立工作目录运行：

```sh
node --test --test-timeout=120000 test/home-phase-one.test.mjs
CHROME_PATH="<浏览器可执行文件>" node test/home-display.browser.mjs
CHROME_PATH="<浏览器可执行文件>" node test/home-performance.browser.mjs
HOME_BASELINE_ROOT="<升级前精确提交的代码目录>" node test/home-upgrade.mjs
npm run verify
```

`home-upgrade.mjs` 要求旧代码具有可验证且干净的 Git 身份或构建清单，拒绝与当前代码相同的路径、提交或构建摘要，并在报告记录两端身份及当前修改状态。它自动创建合成数据目录，检查旧介绍、布局、非默认额度和留言板升级后保留，新能力保持关闭；保存升级前后两个一致快照，在独立目录恢复旧快照运行旧代码，再从保留的新快照恢复新内容。恢复目录缺少配置时立即失败，不用测试默认值补齐。不会对运行实例执行迁移或回滚。

浏览器脚本的输出目录可通过 `HOME_PERFORMANCE_OUTPUT` 指定，报告只含合成测试结果。资源统计为当前浏览器实际响应的编码字节；耗时包含测试机、本机回环网络和动画，不能外推为真实手机、QQ 内置浏览器或移动网络速度。文字对比度检查覆盖三种配色下选中/未选中书签和页脚入口，并合成透明背景；键盘焦点、窄屏、减少动态、字体/素材失败另外检查。这不是整站 WCAG 认证。

## 恢复与回滚操作契约

完整恢复必须保持代码提交、配置、一致 SQLite 在线备份、实际打包素材、目录版本以及许可资料成套；单角色记忆导出不包含实例空间表。恢复时校验数据库完整性及素材 SHA-256，不能只恢复一张截图。组合测试核对恢复后的意图操作 ID、请求号、提交时间与关联账本回执一致，并验证重复执行不增加写入；同时验证配置/数据库及所选资产、目录和许可资料的复制恢复；运行代码来自当前已验证提交，不把它称为独立安装包的完整灾难恢复测试。跨版本演练另使用独立旧版代码目录。

回滚前先备份当前版本及当前新增数据，再恢复升级前的代码、配置和数据库快照。旧程序不认识新的文字槽位/来源或配置字段，不能用旧版写入升级后的运行库。升级后产生的内容不会出现在更早快照中，必须明确保存在当前检查点，后续恢复新版本时取回；不能声称恢复旧快照会自动合并新数据。原发布目录和两个检查点均保留，由维护者决定后续处理。
