# 平台浏览与分享实现、验收及回退

本批实现独立于本机部署，合并不代表启用。全局暂停和角色暂停继续生效；平台权限默认为关闭。视频理解与平台点赞、评论、关注等写操作不在范围内。

## 数据与权限

- 每个角色的 `apps` 设置控制总开关、平台白名单、分享开关、每回合/每日读取预算、每日分享预算、时段、有效期和同目标去重间隔。网页保存设置不改变暂停标志。
- 浏览条目使用该角色已有事件库的 `app.observation`，QQ 卡片保留真实接收消息引用。游标和缓冲内容保存在该角色的 `internal:app-browsing`，一小时过期。下一页只返回未展示的内容；小红书滚动浏览在进程重启后失效，已缓存条目仍可消费。
- 分享复用主体 `intentions` 和既有 outbox。主体只能提出一个目标的意图；目标聊天 `intent_decide` 后通过 `app_share_send` 投递。当前聊天自行浏览的内容也可直接分享。来源必须是自己的实际浏览记录，图片必须已成功登记且与同一记录关联。
- 发送前再次检查权限、时段、来源有效期、目标决定和预算。相同内容按规范化平台 ID 去重；未知或待确认投递不能靠重新浏览换请求重发。相同目标的同伴重复分享、向同伴反射原卡片被拒绝。
- 卡片、帖子和评论都是资料，不是管理指令。卡片摘要、正文、评论、视频简介和图片登记分别标注。原生 QQ App 卡片发送样式未承诺；首版发送自然短评与来源链接，可选已登记图片。

## 平台边界

| 平台   | 入口                                      | 已实现分页             | 明确限制                                                    |
| ------ | ----------------------------------------- | ---------------------- | ----------------------------------------------------------- |
| B 站   | 关注动态、热门、排行榜、搜索              | 关注/热门/搜索         | 未提供首页个性化推荐；视频只读元数据，评论为样本            |
| 知乎   | 推荐、热榜、搜索、回答/文章               | 推荐/搜索              | 评论和问题回答为样本；不把热榜称为推荐                      |
| 小红书 | 推荐、搜索、笔记/评论                     | 推荐滚动与本地余项缓存 | 搜索与评论为有限样本，笔记没有正文时只标元数据              |
| 贴吧   | 热榜话题、指定吧、搜索、帖子              | 吧内列表/楼层页        | 热榜话题需展开帖子；搜索为首批样本                          |
| 小黑盒 | 推荐、板块目录、板块帖子、搜索、帖子/评论 | offset 与本地余项缓存  | Cookie 存在不等于认证有效；没有已验证账号状态时如实标未核验 |

平台调用通过经过审查的 OpenCLI 1.8.4 固定只读适配和小黑盒只读 API。外部安装版本改变时明确拒绝，先重新验收再更新固定版本。浏览器操作共享进程锁串行；浏览记录和游标按角色分开。同一平台账号的推荐可能受两个角色共同浏览影响。

短链接只允许已知平台与 QQ 短链；每次跳转校验域名、DNS、公网地址、凭据参数和跳转次数。已规范化正文地址经 DNS 校验后交给固定平台适配读取，不用匿名访问失败推断已登录浏览也失败。网络图片按既有 SSRF、重定向、大小和文件头规则获取，不接受本机路径。

## 登录与验收

管理员在本机 Chrome 完成登录或扫码，网页只展示官方登录网址和有限状态检查。不在聊天中索要密码、Cookie；不将登录材料写进浏览记录、分享意图或仓库。小红书的单篇公开访问参数保留以免破坏链接，与登录凭据分开处理。

当前开发检查记录（最终交付前更新）：

- 针对性测试覆盖卡片解析、DTD/结构/大小边界、短链 DNS、跨角色引用、分页余项、撤权晚返回、分享过期/未知回执/图片来源。
- 全量回归在初始实现上通过 212 项；后续增量与主体依赖合并后需再次运行 `npm run verify`。
- 小规模真实只读样本：B 站热门/视频元数据/评论、知乎推荐/回答/评论、小红书推荐与继续滚动/笔记元数据/评论、贴吧吧内帖子/楼层、小黑盒推荐/帖子/评论返回真实结果。
- 待完成：主体依赖合入后的联合测试，真实 DSH/Codex 全链路验收、管理台 UI 操作和最终审查。真实 QQ 投递未获本批授权，只使用本机测试网关。

## 升级与回退

1. 保持机器人暂停，备份配置和数据库，再部署经过验收的 main；本任务只合并代码，不执行这次部署。
2. 没有新的独立分享表或调度器。浏览事件和游标随已有数据库备份，分享意图随主体模块导出。旧配置自动补充关闭的平台权限；两种后端都需生成/加载包含新工具的独立工具配置。
3. 管理台逐角色开启需要的平台和分享设置，并检查实际登录状态。启用工具不会解除暂停；恢复运行由管理员另行决定。
4. 回退前先暂停并关闭平台权限，等待在途投递记录完成或标记未知；不要重放未知结果。保留数据库、意图和原始出站回执，回退代码到已备份版本。浏览游标可丢弃，实际消息回执不能删除来触发重发。
