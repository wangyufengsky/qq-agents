# 回合失败与会话恢复

普通工具错误（包括 Codex 动态工具参数无法解析）仍作为工具失败结果返回模型，由模型修正参数或换一种办法，不退役会话。

DSH/Codex 在连接准备阶段失败、尚未对已有会话提交输入时，记录本轮失败并保留原会话，等待连接恢复后的正常唤醒。这项判断只来自适配器明确标记的准备阶段，不从错误文案猜测，也不据此自动重放输入。原生会话恢复失败、创建新会话后的初始化失败以及提交后的未知执行状态仍沿用原有归档边界。

对后端已经明确结束的异常回合，桥接区分错误类型：

| 情况                                                                  | 行为                                                                                                                              |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| DSH `MALFORMED_RESPONSE`                                              | 重新订阅并读取原生快照；最后一个回合事件必须是同一轮、同一错误的 `turn/end`，且两个输入队列均为空。通过后在同一会话自动续接一次。 |
| Codex `responseStreamDisconnected` / `responseStreamConnectionFailed` | 仅缺省 HTTP 状态或 5xx 视为暂时错误。`thread/read` 必须确认原线程空闲且最后一轮对应同一失败；随后在原线程续接一次。               |
| 登录、额度、限流、权限、上下文上限、未知错误                          | 保留分类诊断，不自动重试；沿用退役和历史归档流程。                                                                                |
| 连接中断、会话失效、验证失败或队列仍忙                                | 不猜测原请求是否执行，不自动重放。                                                                                                |
| 管理员暂停、重置、停机、回合超时                                      | 取消优先，不自动继续；沿用取消和超时处理。                                                                                        |

每次续接提交前再次核实原生状态。每个桥接回合最多自动续接一次；续接仍失败但原生状态可验证时，保留会话并记录失败，等待下一次正常输入。聊天和主体思考共用此策略。模型回合记录保留各次后端回合 ID、错误分类、自动续接次数和投递锁定状态；不记录提供商原始错误正文。

## 投递防重

续接保留原能力上下文、隐私标记、发送预算与回执，不重新播放原始提示词或 `tools/call`。

失败前没有投递尝试时，续接可以完成尚未发出的回复。如果已有投递尝试（包括排队中、请求进行中、成功、失败或结果未知），本次续接锁定全部新增 QQ 投递：文字、媒体、文件及操作均经过同一个出口。换 `requestId`、改写文案或换工具不能绕过。原 ID 的成功回执仍可查询，未知回执不会重发。该锁只作用于这次续接，后续正常输入仍可正常回复。

这会保守地截住失败前已经发出第一句后的新增补充，避免将换句话的重发误判为新回复。取消或运行中进程退出仍采用原有归档流程；正常升级和 `robots.mjs restart` 先等待回合完成，保留仍兼容的会话。本功能不恢复历史上已退役的会话，也不重发其消息。

## 验证

`node --test test/turn-recovery.test.mjs` 通过真实后端适配器和 Runtime、模拟原生事件及 QQ 网关，覆盖会话续接、验证竞态、续接上限、取消、各回执状态、排队发送、改 ID/文案、主体及学习回合、普通工具失败和迟到的旧回合通知。DSH 快照契约另以只读方式核对已失败的真实会话；Codex 错误/线程状态契约对照本机 CLI 导出的 JSON schema。

以上不等于已经复现并验证真实提供商再次生成成功，也不发送真实 QQ 测试消息。
